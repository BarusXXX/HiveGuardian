**Alpha build · v1.0.0-alpha.24**

Produced by **BarusXXX and about 15 AI Agents**.

## The game

Protect a Maltese honey bee colony in a flowering Mediterranean garden.
Manage the colony, build its defences and take flight as a single worker bee.
This alpha release is still being refined.

Choose **Deploy Colony**, then **First Flight** to learn the controls.
New players get a short guide to First Flight, the view icons, hive defences
and beekeeper support. The mission pauses during the guide. Skip it at any time;
use **Show quick tour** in Options to see it again.
Open **Build & upgrades**, choose a category and an available defence, then select
an empty mounting point to build it. The menu closes for placement; use × to cancel.
Keep enough workers
foraging, deliver nectar and pollen, and protect the hive's entrance and brood.
Use **Take Flight** to control an individual bee in the same colony.

## Controls

| Control | Action |
| --- | --- |
| W / A / S / D | Pan in strategy view; fly or walk in bee view |
| Drag the scene | Pan in strategy view; touch drag looks around in bee view |
| Move the mouse | Look around in captured desktop flight without holding a button |
| Hold Alt | Free the cursor for buttons; release Alt to return to flight |
| Mouse wheel | Zoom in strategy view |
| Q / E | Descend / ascend while hovering |
| F | Land / lift off |
| H | Return to the hive |
| R | Rally guards |
| Space | Pause strategy view |
| X | Use the worker's one-use last sting; this bee dies on impact |
| Tab | Switch between strategy and bee view |
| T | Cycle normal → half → quarter speed → pause |
| Escape | Release the mouse and pause; pause / resume when using the cursor |

In flight, look up or down while moving forward to climb or dive.
Hover close to flowers to gather pollen and nectar automatically. Approach the
hive entrance to deliver foraged cargo automatically. Completion rings, particles
and short sound cues confirm pickup and delivery. Biting nearby hostile hornets
is automatic, with its own impact effect and sound. The red **Sting · 1 use**
button stays labelled on phones and sacrifices the worker when it strikes.

On mobile, use the **bar-chart icon** in the top bar to show or hide colony
resources, population roles and guard settings. These stats start closed.
Tap the chart again or touch the garden/model view to close them; you can still
pan or fly with the same gesture. The controls remain compact after rotation.
The field guide is available in Options.

The bee panel shows a heart with health percentage and cargo icons with carried
amounts/capacities, such as 1.2/3 pollen. Partial loads carry over between flowers
and saves: visit another flower to keep filling up. Confidence appears in the
top bar. Poison adds a skull icon and countdown beside health.

Touching treated meat on the marking dispenser's tray automatically picks up
one piece and immediately poisons the bee. A bee can carry only one piece at a
time; staying at the tray does not take more. Health declines until death within two game
minutes; the health display shows the remaining time. Returning home or changing
views does not cure it. Pause freezes this timer and slow mode slows it down.
Land at the edge of water to drink automatically.
Flower landings guide the bee onto the flower's centre, including tiny olive
blossoms. Once landed, the bee moves with the flower in the breeze.
At the hive, entry/exit and pollen/nectar loading icons appear below the flight
action buttons. Use the existing Strategy button to manage the colony.

On desktop, selecting the bee icon captures the mouse for continuous turning.
Hold **Alt** to release the cursor and use buttons without changing the view;
release Alt to fly again. **Esc** releases the mouse and pauses. Click the garden
to resume normal-speed flight. If capture is unavailable, drag the garden to look.

On touch screens, use the flight stick, drag to look, and the altitude and action
buttons. Drag to pan and pinch to zoom in strategy view.
Phones keep compact icon controls in portrait and landscape. Health, cargo and
colony confidence sit in the upper corner in flight. The mobile minimap is off by
default: tap the map icon in the header tools to open it in either view,
then tap anywhere to close. It only draws while open; closing also consumes that
tap so it does not activate a control underneath. Desktop strategy retains its map.
The top bar centres **Your Hive**, the next assault clock/speed control and
**Hornet Nest** side by side in both views, with matching population text.
Confidence is a percentage, turning amber below 50% and flashing red below 25%.
Reduced-motion settings disable flashing. Hover a colony indicator to preview
details. Click/tap it to keep details open and centre the strategy camera on that
colony, leaving bee view if needed. Click/tap outside, use × or press Escape to
close details. The hive details show brood, entrance status and selected equipment.
Selecting equipment opens its controls here. Narrow screens keep all three
indicators together on a second header row. Use the wheel or pinch to zoom.
Two icons attach beneath the centre of the top bar: an isometric hexagon for
strategy and a bee for flight. The selected view stays highlighted.
In bee view, a green house marker points to your hive entrance and shows its
distance. When it is out of view, a green arrow guides you back. It disappears
at the doorway and inside the hive, keeping the entrance clear when you arrive.
The compact strategy card keeps resources and role counts.
Tap an icon for its meaning and full total. Select Low, Medium or High guards
to balance defence against foraging. The battery icon shows reserve and charging
information.
On desktop, clicked resource and role callouts appear beside the cursor, as do
the three sale panels. They stay within the screen; keyboard activation anchors
sale panels to the resource button. Touch keeps the existing mobile placement.

The red **Hornet Nest** indicator to the right of the central clock shows enemy
nest health and hornet population in both views. Hover or click/tap it to see
queen health, treated deliveries, stolen brood meals, nest evidence and
professional response status. Click/tap outside, use × or press Escape to close the details.

A radio-and-shield icon appears beneath **Your Hive** when you have 70% nest
evidence and 100 Support. Click/tap it to request a professional response.
The confirmation chime and message acknowledge the 100 Support payment:
future attack strength is reduced by 65%. Hornets already in the field remain
a threat. The icon becomes a checked green button; hover or click/tap it
to review the protection. Sound respects effects volume, mute and pause.

Each untainted meat meal or worker thorax delivered to the nest adds one hornet
to its population. Intercepted meals and tainted food do not increase population;
tainted food starts the nest's contamination effect.

The build catalogue starts collapsed. Its button shows a **star followed by the Support balance** available
to spend on defences and upgrades. Expand a category to browse items and costs;
locked items explain missing Support, required waves or prerequisite hardware.
Only one category expands at a time, and the catalogue scrolls to fit the screen.

The single button beside the mission clock cycles normal speed, half speed,
quarter speed and pause. After any pause, its next click resumes at normal speed.
It stays in the centre of the header in bee view. Continuing a saved colony starts at normal speed.
Click anywhere in the scene to resume a paused game at normal speed. UI buttons
keep their usual actions.

Every new challenge starts with **zero support**, including First Flight.
Beekeeper support grows slowly: **0.12 points per game second**, or 7.2 per
game minute. Pause stops it and slow speed reduces it. You can also sell surplus
stores by clicking the honey, wax or royal jelly icon, choosing an amount and
confirming the sale. The sale panel previews the stock left and any reserve
warning before you confirm. Amber resource outlines indicate low reserves.

| Reserve to keep | Effect below it, increasing gradually as stores empty |
| --- | --- |
| 80 honey | Worker healing and confidence recovery up to 20% slower |
| 20 wax | Brood development up to 10% slower |
| 10 royal jelly | Brood development up to 15% slower |

Wax and royal jelly shortages combine for at most 25% slower brood development.
Restocking removes these effects; existing brood keeps its progress, including
in saves. Selling small surpluses above these reserves has no penalty.
Very low food remains dangerous: below 15 honey or 5 pollen, brood growth stops;
empty honey stores can harm the queen and workers.

| Goods sold | Support received |
| --- | --- |
| 20 honey | ★ 1 |
| 5 wax | ★ 1 |
| 2 royal jelly | ★ 1 |

Sales use whole batches and cannot exceed your stores or the 5,000 support limit.

Use the fullscreen icon beside Sound on the intro, or in the game header, to
enter or leave fullscreen. Desktop browsers also allow Escape to exit.
If your phone browser cannot enter fullscreen, use **Add to Home Screen** and
launch Hive Guardian from its icon. On narrow phones, the field guide is also
available through Options.

Resource types, attacker tracking and flight actions use icons on desktop and
mobile. Hover or focus a control for its name; resource totals remain visible.
Tap the flight hint icon for advice about the bee's current situation.
The skull beside the sting icon warns that the action sacrifices this worker.

## Language and age guidance

Recommended ages **16+**. The game contains stylized insect combat and death.
Bee voice options are **Off**, **Normal** and **Salty**, with Normal selected by
default. Salty includes strong Maltese language. Parental guidance is advised.
Voice volume and other audio settings are available in Options.

The field guide distinguishes practical beekeeping measures from speculative
game technology. Fictional chemistry and accelerated colony behaviour are
gameplay abstractions, not real beekeeping instructions.

## Saves and offline play

Saves are stored in the browser on the current device. Use the save controls in
Options to save, export or import a colony. Export a save before clearing browser
data or moving to another browser or device.

After the hosted game has loaded successfully and cached its files, it can be
revisited offline in the same browser. External reference and contact links
require an internet connection.

When online, the game checks for updates when opened, when you return to its
tab, and once a minute while visible. Each changed build downloads a fresh
offline cache and removes the previous game cache. An active colony is saved
before the game reloads; choose **Continue Operation** to resume it.
Saved colonies and settings are retained. While offline, the last fully cached
release remains playable until a new release can be downloaded completely.

## Test the release locally

Opening `index.html` directly creates a `file://` address. Browsers block the game's
JavaScript modules at that address. Use a local web server instead.

With the source repository and its dependencies installed, run from the repository root:

```powershell
cd game
npm run preview
```

Open [http://127.0.0.1:4173/](http://127.0.0.1:4173/) in your browser. This serves the
built dist; keep the terminal running while playing.

If you have only this release folder and Python installed, open a terminal in the
folder containing `index.html` and run:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Then open [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

## Hosting this release

This folder is ready for static web hosting. Upload its complete contents to an
HTTPS site, preserving the file names and directory structure. Assets load
relative to the folder containing `index.html`, so the same build works at the
site root or under a folder such as `/HiveGuardian/`.

For GitHub Pages, upload the contents of this folder to your configured Pages
publishing location, including the `.nojekyll` file. Open the published Pages URL,
such as `https://barusxxx.github.io/HiveGuardian/`. The manifest and offline cache
use that folder as their scope. Replace the complete previous release when updating.

Serve `index.html` through a web server rather than opening it as a local file.
No game backend or build tools are needed on the host. Use a browser with WebGL 2
support; select Low graphics in Options if performance is slow on your device.
